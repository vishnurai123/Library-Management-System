# Project Statement

## Problem Statement
Manual library records can make it difficult to track books, members, issue/return transactions, availability, and overdue items. The proposed system provides a simple digital solution for organizing these activities.

## Scope
The system manages books, members, lending transactions, returns, fines, searches, and basic reports. It is designed as a small academic library-management application.

## Target Users
- Librarian
- Library administrator
- Students/members

## High-Level Features
1. Book management
2. Member management
3. Issue and return management
4. Search
5. Reports
6. Validation and error handling
7. Persistent SQLite storage
