# Demonstration Guide

## Start
Run:
```bash
python main.py
```

## Suggested viva/demo sequence
1. View Books
2. Search Books using `Python`
3. View Members
4. Issue a book using a displayed Book ID and Member ID
5. View Active Loans
6. Return the issued transaction
7. View Transaction History
8. View Dashboard Report
9. View Overdue Report

## Test invalid input
- Enter a non-existent Book ID during issue.
- Try issuing a book after all copies are unavailable.
- Enter an invalid email while adding a member.
